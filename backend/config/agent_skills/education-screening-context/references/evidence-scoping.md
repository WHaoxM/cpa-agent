# 求职证据的范围与时效（候选 Skill 参考）

此文件按需读取。它是核证方法与少数来源示例，不是岗位数据库，也没有提供岗位族通用命中率。

## 证据层级与标注

1. **岗位资格**：具体雇主/岗位的当前正式公告或原始 JD。保留 URL/记录标识、原文、发布时间/抓取或核验时间、招聘届别/地区及其 AND/OR/例外。转载和口头转述不可冒充原文。
2. **学校身份/学科事实**：对应主管部门或学校官方页面的确切名单、版次、轮次、发布日期。它说明的是该来源范围内的学校或学科事实，不自动说明招聘结果。
3. **市场软信号**：优先使用时间、地区、岗位族、雇主类型、届别/经验层级和样本范围清楚的复核材料；其次是经审阅的多案例经验，再次是专家启发。单个帖子、朋友转述或无范围的说法只算线索。
4. **候选人竞争证据**：简历/作品/经历的来源、确认状态、时间、个人角色、可核验产出分别记录；缺少指标时不代造数字。

所有市场判断都须说明适用范围、证据类型、时间边界和反例/例外。没有适配来源时，说“目前没有足够的岗位/市场证据”，可给定性提醒，不给百分比；不得将项目内的一般职评立场伪装成雇主规则或量化研究。

## 机制性、非统计的工作假设

当用户需要现实语境、但没有岗位级筛选数据时，可以把下列内容作为**待校准的机制假设**，不能说成观测事实：在投递量大、面试名额有限时，某些招聘流程可能把教育背景当成低成本的初筛代理；若岗位稀缺、研究/数学训练要求高、竞争强，这种摩擦可能更明显。该假设不预测具体企业是否使用学校筛选，也不产生数值概率。

相关学科训练、相近实习/项目、可复核成果和实际招聘渠道，可能改变**非硬门槛**环节的竞争材料；哪一项对特定雇主有效仍须由当前 JD、招聘方口径或有范围的案例验证。任何候选证据都不能覆盖公告明示且不允许替代的资格条件。学科评估、项目深度或内推都不等于通用“破格”规则。

建议措辞：“一种可能的筛选机制是……；这只是非统计的工作假设，不代表该岗位或雇主已采用。要判断其是否适用，需要……”。避免“基本不可能”“公司都会”“ATS 一定筛除”等绝对句。

## 当前候选包数据状态

此候选包没有附带任何已审核的、按岗位族/地区/雇主类型/届别划分的中国招聘经验规则或真实岗位样本。跨岗位压力案例是**合成测试输入**，不可以从中学习或输出市场结论。超出具体 JD 的判断应优先找范围清楚、可复核的材料；材料暂缺时，只能使用本节明确标记的机制性工作假设，或说明证据不足，不能升级成特定行业/雇主事实。
