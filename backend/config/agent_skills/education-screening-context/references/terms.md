# 术语边界（候选 Skill 参考）

此文件按需读取，不是统一学校分层或打分标准。

## 工作台“双非”

项目中“双非”是组合口径：非 985 **且**非 211 **且**不在用户所指轮次的“双一流”建设高校/学科名单。各标签不是同一份名单，须分别核对相应来源和版本；缺任何一项时，组合结果为未知，而非默认“双非”。该术语是用户工作台语言，不是教育主管部门发布的学校类别，也不直接说明个人能力或招聘结果。

“强双非”等说法只能作为有范围、有证据的经验表达，不可写入官方身份标签。某校某学科的评估结果，最多支持该校该学科该轮次的事实；不能自动泛化到全校、全部岗位或就业表现。

## 学历与资格表达

- **学历层次**与**学位**是不同字段；招聘公告若并列“本科/硕士”与“学士/硕士学位”，分别核对。
- **专业、学习形式、毕业届别、学校标签**是独立条件。未写、未知、歧义不能互相补齐。
- 使用公告原词并保留其分支；“及以上”“或”“同等学力”“可放宽”等不能凭印象简化。

## 不可互换的证据

| 信息 | 可以支持 | 不能单独证明 |
|---|---|---|
| 教育主管部门学校/学科名单 | 特定名单版本中的标签或学科记录 | 本人学籍、个人能力、企业筛选、录用概率 |
| 当前具体岗位公告/JD | 该岗位在该版本明确写出的资格条件 | 其他雇主或其他招聘环节的规则 |
| 候选人项目/实习材料 | 候选人展示的具体经历/产出（按其来源可信度） | 自动满足公告未允许替代的硬门槛 |
| 招聘经验或面试案例 | 明确样本、时间、岗位范围内的软信号 | 全市场规律、具体企业政策或统计概率 |
